# 맵 레퍼런스 스크린샷

실제 아트가 아니라, `stageGenerator.generateStage()`가 만든 스테이지 데이터를 SVG로 그려 PNG로 변환한 디버그용 평면도다(카메라 줌·캐릭터·그림자 스프라이트 미반영). 절차적 생성 튜닝값을 팀 회의에서 논의할 때 참고용으로 쓴다.

- `default-seed-map-2026-07-28.png`: `DEFAULT_SEED`(12345) 스테이지, Jump King식 난이도 튜닝(`PATH_STEPS=80`, `MIN_SPAN_CELLS=16`, `MAX_AI_BLOCKS=6`) 반영 직후 상태. 경로 길이 81칸, 체크포인트는 27·53번째 칸.
