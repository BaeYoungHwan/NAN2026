## 1. 품질 속성 목표 (Quality Attributes)

| 속성 | 목표 | 측정 방법 | 우선순위 |
|------|------|-----------|----------|
| 접근성(실행 편의성) | 설치 없이 링크 클릭만으로 브라우저에서 즉시 플레이 | 심사자 관점 실사용 테스트 (링크→플레이 소요 클릭 수) | High |
| 성능 | 60 FPS 유지 (그림자 궤적/각도 계산 포함) | 프레임 타임 측정, 프레임 드랍 육안 체크 | High |
| 정확성 | 그림자 경계 포함(containment) 판정이 기하학적으로 정확하게 동작 | 정점·공선 등 경계 케이스 단위 테스트 | High |
| 이식성 | 주요 브라우저(Chrome/Edge) 최신 버전에서 동일 동작 | 크로스 브라우저 수동 테스트 | High |
| 유지보수성 | 48시간 본행사에서 재사용/확장 가능한 단순 구조 | 코드 리뷰, 모듈 분리도 확인 | Medium |
| 규정 준수성 | 대회 제출 규정(웹/앱만, 유료 라이선스 금지 등) 100% 충족 | 제출 전 체크리스트 검증 | High |

## 2. 아키텍처 제약사항

### 기술적 제약
- 웹 브라우저에서 실행 가능해야 함 (PC 실행파일 .exe 제출 불가)
- 키보드 단독 조작만으로 완전 플레이 가능해야 함 (마우스 컨트롤 미지원)
- 별도 유료 라이선스/에셋 스토어 결제 없이 실행 가능해야 함
- GitHub Pages로 정적 배포 가능한 구조 (서버리스 — 백엔드 인프라 없음)
- 절차적 스테이지 생성·이동 패턴 학습 AI는 클라이언트(JS) 측에서 전량 수행 (서버 비용 없음)

### 조직적 제약
- 2인 팀 (배영환: 백엔드/아키텍처/데이터, 송원호: 프론트엔드/UI/QA) — API·인터페이스 계약을 초반에 합의하면 병렬 진행 가능한 조합
- 사전과제 마감(2026-08-10)까지 약 18일 — 구현, 문서화(PDF 3종)까지 포함해야 하므로 아키텍처는 단순함을 최우선

### 예산/인프라 제약
- 예산 사실상 없음 — 무료 티어(GitHub Pages 등) 내에서 해결
- 외부 유료 API/서비스 의존 최소화

## 3. 주요 아키텍처 결정 (초안)

> 상세 결정 기록은 `docs/design-docs/adr/` 에 ADR로 작성합니다.

| 결정 영역 | 선택 | 근거 |
|-----------|------|------|
| 실행 환경 | 브라우저(클라이언트 사이드) | 설치 없이 심사자가 바로 플레이해야 함 |
| 백엔드 필요 여부 | 불필요 (클라이언트 단독 게임) | 서버 인프라·배포 복잡도 최소화, 무료 정적 호스팅으로 충분 |
| 배포 | GitHub Pages | 대회가 명시적으로 권장하는 방식, 무료, 링크 공유만으로 심사 가능 |
| UI / 렌더링 스택 | React (UI) + HTML5 Canvas (게임 렌더링) | UI는 선언적으로 관리하고, 그림자 계산·경계 포함 판정처럼 매 프레임 갱신되는 로직은 Canvas 직접 제어로 성능 확보 |
| 그림자 경계 판정 | 기하학적/벡터 방식 확정 (point-in-polygon + 선분-다각형 교차, 그리드·픽셀 기각) | 그리드는 셀 양자화 오차로 정확도 리스크, 픽셀은 readback으로 60 FPS 리스크 — 기하 방식이 해석적으로 정확하고 연산 비용도 가장 낮음 |

| 2인 팀 병렬 작업 중 API/인터페이스 계약 불일치 | Medium | Medium | 초반에 게임 상태/이벤트 인터페이스를 문서로 합의 후 병렬 진행 |

## 5. 검증 기준

아키텍처가 이 ARD를 만족하는지 확인하는 방법:

- [ ] 링크 클릭만으로 설치 없이 브라우저에서 플레이 가능 (실사용 테스트)
- [ ] 60 FPS 유지 확인 (프레임 타임 측정)
- [ ] Chrome/Edge 최신 버전에서 동일하게 동작
- [ ] 그림자 경계 이탈(containment) 판정 경계 케이스 테스트 통과
- [ ] 제약사항 위반 없음 — `architecture-guard.sh` 훅 통과
- [ ] 주요 결정사항 ADR 작성 완료 (`docs/design-docs/adr/`)
- [ ] 사전과제 제출 규정 체크리스트 100% 충족
