## 1. 공간 개념도 — 두 객체, 두 조작

플레이어는 **캐릭터**(WASD)와 **그림자**(`,`/`.` 회전)를 동시에 조종한다. 안전 구역(파란 부채꼴)은 광원 위치 `L`과 캐릭터 위치 `C`로 매 프레임 다시 계산되는 "자연 각도" 기준으로 캐릭터에 붙어 다닌다. 그림자(초록/빨강 선)는 광원과 무관하게 플레이어가 마지막으로 맞춰놓은 각도를 그대로 유지한다.

```
                              ☀ L (광원, 스테이지 고정)
                             ╱
                            ╱  ← 자연 각도 = atan2(C - L)
                           ╱      (안전 구역의 중심 방향, 매 프레임 재계산)
                          ╱
                         ●C  (캐릭터, WASD로 이동)
                        ╱│╲
                       ╱ │ ╲   ← 안전 구역 (자연 각도 ± 허용치, 부채꼴)
                      ╱  │  ╲
                     ╱   │   ╲
                    ╱────┼────╲
                        (그림자, , . 로 회전 — 부채꼴 안에 있어야 생존)
```

- **캐릭터**를 움직이면 `C`가 바뀌고, 그에 따라 "자연 각도"(부채꼴의 중심)도 바뀐다.
- **그림자**는 `,`(시계방향)/`.`(반시계방향)로 직접 돌리지 않는 한 각도가 그대로 유지된다.
- **판정 규칙: 그림자 각도와 자연 각도의 차이가 허용치(±30도, 임시값) 이내여야 한다. 벗어나면 그 프레임에 즉사 + 스폰 위치로 리셋.**

---

## 2. 왜 "이중 조작"이 재미인가

캐릭터를 움직이는 것과 그림자를 맞추는 것은 서로 다른 축이다. **가만히 있으면 그림자는 안전하게 유지되지만, 캐릭터를 움직이는 순간 안전 구역이 따라 움직이며 그림자와 어긋나기 시작한다.**

```
[캐릭터가 가만히 있을 때]        [캐릭터를 이동시킬 때]
자연 각도 고정                   자연 각도가 이동 방향에 따라 계속 바뀜
→ 그림자도 가만히 두면 안전       → 그림자를 함께 회전(,/.)시켜야 안전 유지
                                 (안 돌리면 부채꼴이 그림자를 스쳐 지나가며 이탈)
```

즉 "통로를 이동하면서 동시에 그림자 각도를 계속 맞추는 것"이 핵심 도전이다. 절차 생성 AI가 학습한 플레이어의 이동 패턴을 막을 때도, 이동 자체를 어렵게 만드는 지형뿐 아니라 "이동 중 각도를 맞추기 힘든 궤적"을 활용할 수 있다.

## 3. 프레임 단위 판정 흐름

```mermaid
flowchart LR
    A1[WASD 입력] --> B1[캐릭터 위치 갱신<br/>physics: 벽 충돌 반영]
    A2[, . 입력] --> B2[그림자 각도 갱신<br/>shadow: 독립 상태, 자동 복귀 없음]
    B1 --> C[ShadowCaster<br/>자연 각도 = atan2 C - L]
    B2 --> D
    C --> D{ContainmentJudge<br/>|그림자각 - 자연각| ≤ 허용치?}
    D -- 이탈 --> E[즉사 → 캐릭터·그림자각 모두<br/>스폰 값으로 리셋]
    D -- 정렬 --> F[Canvas 렌더 → 다음 프레임]
    E --> A1
    F --> A1
```

이 판정은 **매 프레임(60회/초)** 반복된다. 캐릭터 이동과 그림자 회전이 서로 다른 키 입력이라는 점, 그리고 안전 구역이 레벨이 아니라 **캐릭터에 부착**되어 있다는 점이 예전 기획안과의 핵심 차이다.

## 4. 예전 기획(오기획)과 차이

| 항목 | 예전 서술 (폐기됨, ADR-001) | 현재 확정 (ADR-002) |
|------|---------------------------|----------------------|
| 조작 대상 | 캐릭터만 (그림자는 파생값) | 캐릭터 + 그림자 (둘 다 직접 조작) |
| 그림자 각도 | 광원+캐릭터 위치로 매 프레임 자동 계산 | 플레이어가 `,`/`.`로 직접 설정, 자동 복귀 없음 |
| 안전 구역 | 스테이지에 고정된 폴리곤 (`boundaryPolygon`) | 캐릭터에 부착되어 매 프레임 재계산되는 각도 범위 |
| 판정 방식 | 선분이 폴리곤 안에 포함되는가 (point-in-polygon) | 그림자 각도가 자연 각도 ± 허용치 안인가 |

## 5. 아직 안 정한 것 (플레이테스트 필요)

- 허용 각도(현재 임시값 ±30도), 그림자 회전 속도(현재 임시값 180도/초), 그림자 길이(현재 임시값 80px) — 실제로 움직여보며 난이도가 적절한지 확인 필요
- 장애물이 그림자 회전 가능 범위를 물리적으로 막는 기믹을 추가할지 — 현재는 MVP 범위 제외
