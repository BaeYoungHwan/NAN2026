### B. 맵 디자인 — 제출 범위에서 제외 (2026-08-05 결정)

- [x] **결론: 이번 사전과제 제출은 현재 절차적 생성 맵 그대로 간다.** 시드가 `DEFAULT_SEED = 12345`로 고정돼 있어(`procgen/stageGenerator.ts`) 매 플레이 동일한 지형이 나온다 — 플레이어 체감상 이미 고정 맵과 같다. "광원·스폰·골을 고정값으로 전환"은 순수하게 내부 표현 문제이고 화면에 드러나는 차이가 없으므로, 마감 5일 전에 세 스테이지를 전부 갈아엎을 이유가 없다. 본선/이후 개발로 이월 ([[project-procgen-temporary-scope]], ADR-004 "재검토 조건")
- [x] **맵 크기를 캔버스에서 분리 (2026-08-05)** — 맵 크기가 `GRID_COLS = CANVAS_WIDTH / TILE_SIZE`로 캔버스에 묶여 20×15 = 300셀뿐이었다. 그 안에서 통로를 80스텝 carve하니 통로가 자기 자신을 반복해 덮어써, 미로가 아니라 뭉개진 열린 공간이 되기 쉬웠다(ADR-003의 300시드 전수 실측 기록과 같은 원인). `tuning.worldCols`/`worldRows`로 분리하고 카메라 클램프를 `stage.grid` 기준으로 바꿔 맵이 화면보다 커질 수 있게 했다. **기본값은 20×15로 현재 맵과 동일하게 유지** — 넓힐지는 플레이테스트로 결정할 사항이라 실험 경로만 열어뒀다(`?tune=1`의 "맵 가로/세로" 슬라이더, 40×30 브라우저 실측 정상 동작 확인)
