# 플레이 영상 촬영 계획 (30~60초)

> 제출물 5종 중 2번. 유튜브 공개 업로드 후 **링크만** 제출한다(레포에는 영상 파일을 넣지 않는다).
> 작성: 2026-08-06 (사전 준비) · 촬영 예정: 밸런스 확정 직후

제출물 중 유일하게 미착수 항목이고, 밸런스 확정에 물려 있어 가장 늦게 시작된다. 당일에 "무엇을 찍을지"부터 고민하지 않도록 컷을 미리 정해 둔다.

## 콘티 (총 55초 기준)

| 구간 | 시간 | 화면 | 노리는 것 |
|---|---|---|---|
| 1 | 0:00~0:05 | 타이틀 화면 (제목 + 로그라인 + 조작 안내) | 게임 이름을 먼저 각인. **BGM이 들리도록 소리를 켜고 시작** |
| 2 | 0:05~0:11 | 오프닝 컷신 중 2장 — "여기는 이승과 저승의 경계" + 저승사자 대사 | 세계관을 6초 안에. 나머지 3장은 건너뛴다 |
| 3 | 0:11~0:26 | **1R 플레이** — 부채꼴 가이드 안에 그림자를 유지하며 이동. 중간에 세이브 포인트(파란 원) 통과 | 핵심 메커닉을 보여주는 구간. **이동과 회전을 동시에** 하는 장면이 반드시 들어가야 한다 |
| 4 | 0:26~0:32 | **사망 장면** — 일부러 그림자를 안전 구역 밖으로 돌려 사망 → 리스폰 | "그림자가 벗어나면 즉사"라는 규칙을 말이 아니라 화면으로 설명 |
| 5 | 0:32~0:41 | **2R** — 가이드 부채꼴이 없는 상태로 플레이 | 라운드마다 난이도가 올라간다는 것을 보여준다 |
| 6 | 0:41~0:51 | **3R** — HUD의 붉은 "디메리트: 이동키 반전 + 허용 각도 축소" 문구가 화면에 잡히게 | 디메리트 시스템 |
| 7 | 0:51~0:55 | 엔딩 결과 요약 (총 사망 횟수 / 클리어 시간) | 마무리 |

**우선순위**: 60초를 넘기면 3번(1R)과 5번(2R)에서 줄인다. 4번(사망)과 6번(3R 디메리트)은 이 게임의 정체성이라 빼지 않는다.

## 촬영 체크리스트

**촬영 전**

- [ ] 최종 밸런스가 반영된 **라이브 빌드**로 찍는다 (<https://baeyounghwan.github.io/NAN2026/>) — 개발 서버로 찍으면 `localhost` 주소가 화면에 남는다
- [ ] `?tune=1` 튜닝 패널이 뜨지 않는지 확인 (프로덕션 빌드에서는 원래 안 뜬다)
- [ ] 브라우저 전체 화면(F11) — 북마크바·탭·주소창이 안 나오게
- [ ] 창 크기는 4:3에 가깝게. 캔버스는 화면에 맞춰 확대되므로 세로가 너무 낮으면 게임 화면이 작아진다
- [ ] **소리 켜짐** 상태 확인 (HUD의 "🔊 소리 켜짐"). BGM은 CC-BY 곡을 포함하므로 크레딧이 타이틀 화면에 보이는 채로 시작하는 것이 안전하다
- [ ] 알림·메신저 팝업 차단

**촬영 중**

- [ ] 1R은 **깔끔하게** — 헤매는 장면이 길면 지루하다. 몇 번 연습 후 촬영
- [ ] 사망은 **일부러** 낸다 (`,` 또는 `.`를 길게 눌러 그림자를 밖으로). 3R보다 1R에서 내는 편이 화면이 밝아 잘 보인다
- [ ] 마우스 커서를 게임 화면 밖에 두거나 움직이지 않는다 — 키보드 전용 게임인데 커서가 돌아다니면 인상이 나쁘다

**업로드**

- [ ] 유튜브 **공개** 또는 일부공개. 비공개는 심사자가 못 본다
- [ ] 제목: `돌려돌려 그림자 — NHN NAN2026 사전과제 플레이 영상`
- [ ] 설명란에 플레이 링크와 저장소 링크, BGM 크레딧(CC-BY 2곡: Mystical Theme / Alexandr Zhelanov, Epilogue / tcarisland) 기재
- [ ] 업로드 후 **로그아웃 상태(시크릿 창)에서 재생되는지 확인** — 권한 설정 실수가 가장 흔한 사고다

**촬영 후**
