## 게임 제목 및 한 줄 소개

- **제목**: 돌려돌려 그림자
- **한 줄 소개**: 캐릭터와 그림자를 동시에 조종해, 광원 반대편 안전 구역을 놓치지 않고 이승과 저승의 경계를 넘는 키보드 전용 이중 조작 액션 퍼즐.

---

## 게임 방법

### 배경
저승사자가 동명이인 착오로 주인공을 저승에 데려온다. 아직 죽을 때가 아닌 주인공은 이승-저승 경계를 다시 넘어야 하는데, 경계를 넘는 동안 그림자가 불안정해져 몸과 그림자를 따로 붙잡고 있어야 한다.

### 목표
1R부터 3R까지 순서대로 스테이지를 통과한다. 각 라운드는 절차적으로 생성된 새로운 지형이며, 스폰에서 시작해 세이브 포인트(파란 원)를 지나 골(주황 원)에 도달하면 다음 라운드로 넘어간다. 3R의 골에 도달하면 전체 클리어.

캐릭터를 이동시키는 동안 안전 구역("캐릭터 뒤 ± 허용 각도")이 매 프레임 재계산되며, 그림자는 이 안전 구역과 무관하게 플레이어가 직접 돌린 각도를 그대로 유지한다. 캐릭터가 움직이면 안전 구역도 함께 움직이므로, 그림자를 계속 맞춰 돌려야 한다.

### 조작

| 키 | 동작 |
|----|------|
| `W`/`A`/`S`/`D` 또는 방향키 | 캐릭터 이동 |
| `,` | 그림자 시계방향 회전 |
| `.` | 그림자 반시계방향 회전 |

- **1R**: 안전 구역(부채꼴) 가이드라인이 화면에 표시됨
- **2R**: 가이드라인 제거 — 안전 구역 위치를 스스로 기억/추측해야 함
- **3R (디메리트)**: 허용 각도가 절반으로 축소되고, 캐릭터 이동키(WASD)가 상하좌우 반전됨(그림자 회전키는 영향 없음)

### 종료 조건

- **클리어**: 3R의 골에 도달하면 엔딩 컷신이 재생되고 게임이 종료된다.
- **사망(리셋)**: 그림자 각도가 안전 구역을 벗어나는 순간 즉시 사망 처리되며, 짧은 사망 연출 후 그 라운드 스테이지의 마지막 세이브 포인트(지나친 적이 없으면 스폰)로 리스폰된다. 사망은 "게임 오버"가 아니라 리스폰이며, 별도의 라이프 제한은 없다 — 화면 우측 상단 "재시작" 버튼으로 언제든 1R부터 처음부터 다시 시작할 수 있다.

## 실행 방법

- **플랫폼**: 웹 브라우저(설치 불필요), 키보드 필수(마우스·터치 조작 미지원)
- **권장 환경**: 최신 데스크톱 Chrome/Edge 등에서 확인됨
- **로컬 실행**(소스에서 직접 실행할 경우):
  ```bash
  npm install
  npm run dev       # http://localhost:5173
  ```
