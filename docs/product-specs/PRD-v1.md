## 1. 개요

**Shadow-Step (가제)** — NHN 주최 NAN2026 AI 게임 개발 해커톤(https://nan2026.nhn.com/) 사전과제 제출용 웹 게임. 광원(태양)은 스테이지마다 고정된 위치를 가지며, 캐릭터 위치에 따라 그림자의 궤적/각도가 매 프레임 실시간으로 계산된다. 플레이어는 캐릭터를 이동시켜 이 그림자를 간접적으로 조종하는 키보드 전용 액션 퍼즐 싱글 플레이 게임으로, 그림자가 스테이지에 정의된 안전 경계(바운더리)를 벗어나는 순간 즉사·스테이지 리셋된다.

## 2. 문제 정의

NAN2026은 서류·사전과제 심사를 통과한 10팀만 본행사(2026-09-04~06, 48시간 개발)에 진출할 수 있다. 사전과제는 자유 주제 웹 게임을 완성해 제출해야 하며, 마감(2026-08-10)까지 약 18일밖에 남지 않은 상태에서 컨셉 확정부터 빌드·제출물 5종까지 완료해야 한다. 캐릭터를 직접 조작하지만 실제 생존 여부는 간접적으로 파생되는 그림자의 위치에 달려 있다는 점에서, 시각적 위치와 실제로 필요한 이동 방향이 어긋나는 "간접 조작형 퍼즐"로 차별화해, 짧은 개발 기간에도 완성도 있는 단일 메커니즘 게임을 만드는 것이 목표다.

## 3. 타겟 유저

| 페르소나 | 설명 | 주요 시나리오 |
|----------|------|---------------|
| 심사자 (1차) | NHN 사전과제 심사 담당자 | GitHub Pages 링크 클릭 → 브라우저에서 바로 플레이 → 문서 4종 검토 |
| 플레이어 (일반) | 짧고 명확한 규칙의 퍼즐/인디 게임을 즐기는 웹게임 이용자. 컨트롤보다 정교한 동선 계산과 순발력을 선호 | 브라우저에서 플레이, 짧은 세션 내 핵심 재미(동선 계산) 체감 |

## 4. 성공 지표 (KPI)

- 사전과제 심사 통과 — 전체 지원팀 중 상위 10팀 선발 (2026-08-22 발표)
- 본행사(2026-09-04~06) 수상권(대상/최우수상/우수상) 진입
- 스테이지 평균 클리어율 40~60% 유지 (적절한 난이도)
- 유저 평균 플레이 타임 10분 이상
- 재시도(Retry) 횟수 스테이지당 평균 3회 이상 (도전 욕구 자극)

## 5. 기술 스택

**TypeScript + React + HTML5 Canvas** (확정). UI 레이어는 React, 게임 렌더링·그림자 계산·경계 포함 판정은 Canvas를 직접 제어한다. 절차적 스테이지 생성과 이동 패턴 학습 AI는 클라이언트(JS) 측에서 수행해 서버 비용을 없앤다.

## 6. 배포 환경

GitHub Pages (웹 빌드 필수, 링크 클릭만으로 브라우저에서 바로 플레이 가능해야 함). 저장소: https://github.com/BaeYoungHwan/NAN2026

## 7. MVP 핵심 기능

> 이번 버전에서 반드시 구현할 기능

- [ ] WASD / 방향키 기반의 캐릭터 이동 시스템
- [ ] 광원(태양) 고정 위치 지정 및 캐릭터 위치에 따른 실시간 그림자 궤적/각도 계산 로직
- [ ] 그림자 경계 이탈 판정 (즉사 및 스테이지 리셋 — 그림자가 스테이지의 안전 경계를 벗어나는 순간 발동)
- [ ] 스테이지 지형·광원 위치·안전 경계 절차적 생성 (Procedural Generation)
- [ ] 플레이어의 이동 방향 패턴(자주 가는 동선)을 학습하여 차단하는 절차 생성 AI 알고리즘
- [ ] 실패 시 즉시 재시작(리트라이) 흐름
- [ ] 최소 UI (조작법 안내, 재시작 버튼, 클리어 표시)

## 8. MVP 제외 사항 ⚠️

> Claude는 아래 항목을 임의로 구현하지 않습니다.

- 사용자 회원가입 및 로그인
- 랭킹 시스템 및 글로벌 리더보드
- 마우스 컨트롤 지원 (키보드 단독 조작 원칙)
- 아이템, 스킬, 광원 직접 조작 기믹
- 복잡한 그래픽 셰이더 및 3D 그래픽 효과
- PC 실행파일(.exe) 빌드 — 대회 규정상 제출 불가
- 유료 라이선스가 필요한 에셋 사용

## 9. 제약사항

- 웹 브라우저에서 키보드 단독 조작으로만 완벽 플레이 가능해야 함
- 외부 서버 비용을 최소화하기 위해 클라이언트 측(JS)에서 AI 절차 생성 및 이동 패턴 학습 수행
- PC 실행파일(.exe) 제출 불가 — 웹 또는 모바일 앱만 허용
- 별도 유료 라이선스 없이 심사자가 바로 실행 가능해야 함
- 외부 에셋(이미지·사운드 등) 사용 시 출처·라이선스를 AI 활용 기술문서에 반드시 명시
- AI 도구 사용 내역(도구명, 주요 프롬프트)을 반드시 문서화
- 플레이 영상은 AI 합성·타인 영상 도용 금지, 실제 플레이 화면만 사용
- 저장소는 공개(public) 권장, 비공개 시 심사 계정(dl_gameai_reviewer@nhn.com) 초대 필요

## 10. 팀 / 일정

- 팀: 2인 — 배영환(백엔드/아키텍처/WBS 총괄), 송원호(프론트엔드·UI/콘텐츠/QA)
- MVP 마감: 2026-08-10 (사전과제 제출 마감과 동일)
- 런칭 목표: 2026-09-04 ~ 09-06 (본행사 개발기간)
- 참가팀 발표: 2026-08-22
