# NAN2026 PRD v1

> 버전: v1 | 작성일: 2026-07-22 | 상태: Draft

---

## 1. 개요

NHN 주최 NAN2026 AI 게임 개발 해커톤(https://nan2026.nhn.com/) 사전과제 제출용 웹 게임. 게임 주제는 자유이며 아직 확정되지 않음 (2026-07-22 기준 1일차).

## 2. 문제 정의

NAN2026은 서류·사전과제 심사를 통과한 10팀만 본행사(2026-09-04~06, 48시간 개발)에 진출할 수 있다. 사전과제는 자유 주제 웹 게임을 완성해 제출해야 하며, 마감(2026-08-10)까지 약 19일밖에 남지 않은 상태에서 주제 선정부터 빌드·제출물 5종까지 완료해야 한다. 지금 프로젝트 골격을 잡아두지 않으면 주제 확정 이후 일정이 더욱 빠듯해진다.

## 3. 타겟 유저

| 페르소나 | 설명 | 주요 시나리오 |
|----------|------|---------------|
| 심사자 (1차) | NHN 사전과제 심사 담당자 | GitHub Pages 링크 클릭 → 브라우저에서 바로 플레이 → 문서 4종 검토 |
| 플레이어 (일반) | 게임을 실제로 즐기는 일반 사용자 | 브라우저에서 플레이, 짧은 세션 내 핵심 재미 체감 |

## 4. 성공 지표 (KPI)

- 사전과제 심사 통과 — 전체 지원팀 중 상위 10팀 선발 (2026-08-22 발표)
- 본행사(2026-09-04~06) 수상권(대상/최우수상/우수상) 진입

## 5. 기술 스택

미정 — 웹 브라우저 실행이 필수 조건. 주제 확정 시점에 엔진/라이브러리 결정 (후보: Phaser, 바닐라 JS+Canvas, Unity WebGL 등).

## 6. 배포 환경

GitHub Pages (웹 빌드 필수, 링크 클릭만으로 브라우저에서 바로 플레이 가능해야 함). 모바일 앱(APK/테스트 링크)은 선택사항.

## 9. 제약사항

- PC 실행파일(.exe) 제출 불가 — 웹 또는 모바일 앱만 허용
- 별도 유료 라이선스 없이 심사자가 바로 실행 가능해야 함
- 외부 에셋(이미지·사운드 등) 사용 시 출처·라이선스를 AI 활용 기술문서에 반드시 명시
- AI 도구 사용 내역(도구명, 주요 프롬프트)을 반드시 문서화
- 플레이 영상은 AI 합성·타인 영상 도용 금지, 실제 플레이 화면만 사용
- 저장소는 공개(public) 권장, 비공개 시 심사 계정(dl_gameai_reviewer@nhn.com) 초대 필요
- 48시간 본행사 대비, 사전과제 단계에서부터 확장 가능한 단순 구조 유지

## 10. 팀 / 일정

- 팀: 2인 — 배영환(백엔드/아키텍처/WBS 총괄), 송원호(프론트엔드·UI/콘텐츠/QA)
- 사전과제 제출 마감: 2026-08-10
- 참가팀 발표: 2026-08-22
- 본행사(48시간 개발): 2026-09-04 ~ 09-06
